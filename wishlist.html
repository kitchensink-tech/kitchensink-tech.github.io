New!

Callout/admonition sections just landed. This box is one, authored via a callout.json section interleaved with main-content sections; kind can be note, tip, warning, important/danger, or anything else (unstyled fallback). The body is plain text for now, no markdown rendering yet.

Main-content and callout sections render in the order they appear in the source file, so authors can interleave prose and admonitions freely. Two more section types landed alongside callouts:

Does a faq section support markdown in answers?

Not yet, same plain-text limitation as callout bodies.

Can I have more than one faq section per article?

Yes, they render in file order just like callouts and main-content.
