This is the same playground built from the [tramaj](https://github.com/lucasdicioccio/tramaj ) repository's PureScript sources, published here as a static bundle so it can be tried without a local build. It parses and evaluates tramaj expressions and documents in the browser — nothing is sent to a server.

See [Tramaj sections](/sections-templating.html ) for how the same language is embedded server-side, as a section pre-processor, by KitchenSink itself.

```html
<iframe class="playground-frame" src="/templating-playground.html" title="tramaj playground"></iframe>
```

If the embedded frame does not load, open the [playground](/templating-playground.html ) directly.
