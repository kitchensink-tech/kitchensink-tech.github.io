This is the same playground built from the templating-lang repository’s PureScript sources, published here as a static bundle so it can be tried without a local build. It parses and evaluates templating-lang expressions and documents in the browser — nothing is sent to a server.

See Templating-lang sections for how the same language is embedded server-side, as a section pre-processor, by KitchenSink itself.

If the embedded frame does not load, open the playground directly.
